# Scratchpad

an experimental AutoHotkey v2 scratch drawer for quick notes and code, using Notepad3 as its editor.

requires Windows, 64-bit AutoHotkey v2, and Notepad3.

**status:** early development. functionality may change.

## usage

run `scratchpad.ahk`. the default toggle is `Win + F12`.

settings and startup options are available through the tray menu.
