# Win Key Overhaul

AutoHotkey v2 window management utilities that replace and extend Windows keyboard shortcuts.

includes window layouts, navigation, stretching, swapping, borderless fullscreen, and optional FancyZones integration.

**status:** experimental. functionality and keybindings may change.

## usage

run `win-key-overhaul.ahk`.

see [documentation](win-key-overhaul/README.md) for controls and settings.
